# Console-Based Tic Tac Toe (Java)

A simple command-line Tic Tac Toe game built in Java to practice Object-Oriented Programming and design patterns like
Strategy, Factory, and MVC (Model-View-Controller).

## 📌 Features

- Supports variable board size (e.g., 3x3, 4x4)
- Supports multiple players (X, O, etc.)
- Pluggable winning strategies:
    - Row strategy
    - Column strategy
    - Diagonal strategy
- Undo functionality
- Clean modular design using design patterns

## 🛠️ Design Patterns Used

- **Strategy Pattern** – for flexible winning condition checks
- **Factory Pattern** – to create game strategy objects
- **Builder Pattern** – to create game object
- **MVC Pattern** – to separate game logic, models, and control flow
